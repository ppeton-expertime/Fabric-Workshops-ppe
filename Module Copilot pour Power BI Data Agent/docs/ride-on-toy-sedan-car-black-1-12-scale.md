# Ride on Toy Sedan Car (Black) 1/12 Scale

## Product Overview
The Ride on Toy Sedan Car (Black) 1/12 scale is a compact ride-on style toy designed to simulate a sedan driving experience for children in supervised play environments.

## Key Features
- 1/12 scale sedan-inspired design
- Black body color
- Compact format for controlled play areas
- Durable shell for repeated casual use

## Typical Use Cases
- Indoor playrooms
- Smooth outdoor surfaces
- Vehicle-themed role-play activities

## Basic Usage Instructions
1. Inspect the toy before each session.
2. Use on flat, stable, and obstacle-free ground.
3. Seat the child properly and supervise continuously.
4. Clean and store after use.

## Safety Notes
- Follow manufacturer age and weight recommendations.
- Keep away from traffic areas, ramps, and stairs.
- Stop using if any structural part becomes loose or damaged.

## Care and Storage
- Store in a dry, shaded location.
- Wipe with mild soap solution and soft cloth.
- Check wheel condition periodically.
