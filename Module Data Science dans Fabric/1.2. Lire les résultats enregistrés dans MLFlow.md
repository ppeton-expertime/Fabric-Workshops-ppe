# 1.2. Lire les résultats enregistrés dans MLFlow

Ce guide explique comment consulter et interpréter les résultats enregistrés dans **MLflow** après l'entraînement d'un modèle dans Microsoft Fabric.

## Prérequis

- Un notebook a déjà été créé.
- Un entraînement de modèle a été exécuté avec journalisation MLflow.
- Les métriques, paramètres et artefacts ont bien été enregistrés dans une expérience.

## 1. Ouvrir l'expérience MLflow

1. Dans le notebook ou dans le workspace Fabric, ouvrir le volet **MLflow** ou l'expérience associée.
2. Repérer l'expérimentation utilisée pendant l'entraînement.
3. Afficher la liste des runs disponibles.
4. Identifier le run le plus récent ou le plus performant.

> **Zone capture d'écran 1** : insérer ici une capture de l'expérience MLflow affichant la liste des runs.

## 2. Lire les informations d'un run

1. Ouvrir un run précis.
2. Vérifier les **paramètres** utilisés pour l'entraînement.
3. Consulter les **métriques** calculées, par exemple :
   - `rmse`
   - `mae`
   - `r2`
4. Comparer ces valeurs pour comprendre si le modèle est satisfaisant.

Exemple de lecture logique :

- un `rmse` faible indique une erreur moyenne plus faible ;
- un `mae` faible signifie que les prédictions sont proches des valeurs réelles ;
- un `r2` proche de 1 indique un bon niveau d'explication de la variance.

## 3. Comparer plusieurs runs

1. Sélectionner plusieurs runs dans l'expérience.
2. Comparer les métriques principales.
3. Identifier le meilleur compromis entre performance et simplicité.
4. Conserver le run le plus pertinent pour la suite du projet.

## 4. Lire les artefacts enregistrés

1. Ouvrir l'onglet **Artifacts** du run.
2. Vérifier les fichiers produits par l'entraînement, par exemple :
   - modèle sauvegardé ;
   - courbe d'apprentissage ;
   - tableau de prédictions ;
   - fichier de configuration.
3. Télécharger ou afficher les artefacts utiles pour l'analyse.

> **Zone capture d'écran 3** : insérer ici une capture de l'onglet Artifacts avec les fichiers du run.

## 5. Lire les résultats depuis le notebook

1. Importer MLflow dans une cellule du notebook.
2. Charger l'expérience ou le run à analyser.
3. Extraire les métriques et les afficher proprement.
4. Utiliser les artefacts pour vérifier le comportement du modèle.

Exemple de code :

```python
import mlflow

experiment = mlflow.get_experiment_by_name("Nom_De_L_Experience")
runs = mlflow.search_runs(experiment_ids=[experiment.experiment_id])

display(runs)
```

Exemple pour lire un run précis :

```python
run_id = runs.iloc[0]["run_id"]
run = mlflow.get_run(run_id)

print(run.data.params)
print(run.data.metrics)
```

## 6. Interpréter les résultats

1. Vérifier si les métriques sont cohérentes avec l'objectif métier.
2. Comparer le modèle à une version précédente si elle existe.
3. Identifier les éventuels signes de surapprentissage ou de sous-apprentissage.
4. Décider si une nouvelle itération est nécessaire.

## 7. Exploiter les résultats pour la suite

1. Conserver le meilleur run comme référence.
2. Utiliser le modèle sauvegardé pour les tests ou la réutilisation.
3. Noter les paramètres et les métriques retenus dans le notebook.

Le lecteur peut maintenant consulter rapidement les résultats MLflow et comprendre comment comparer les runs, lire les métriques et exploiter les artefacts enregistrés.
