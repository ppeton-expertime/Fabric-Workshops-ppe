# 2.3. Utiliser PREDICT en batch sur de nouvelles données

Ce guide explique comment utiliser la fonction **PREDICT** en mode batch dans Microsoft Fabric pour produire une prévision sur un ensemble de nouvelles données.

Le principe est le suivant :

- préparer un fichier de nouvelles observations ;
- déposer ce fichier dans le **Lakehouse** du workspace **[FORMATION]** ;
- le charger dans une table ou un dataframe ;
- appliquer **PREDICT** sur toutes les lignes en une seule fois ;
- enregistrer les résultats de prévision.

## Prérequis

- Un modèle de prédiction a déjà été entraîné et enregistré.
- Le modèle est accessible depuis l'environnement Fabric utilisé pour le scoring.
- Le Lakehouse cible est disponible dans le workspace **[FORMATION]**.
- Le fichier de nouvelles données d'exemple est présent dans le sous-dossier **data** du module.

## 1. Utiliser le fichier de nouvelles données fourni

Le fichier d'exemple à utiliser pour cette étape est :

- **data/nouvelles-donnees-predict-batch-100.csv**

Ce fichier contient **100 lignes** de nouvelles observations avec une structure simple :

- `station`
- `jour`
- `heure`

> **Important** : les colonnes du fichier d'entrée doivent correspondre aux variables attendues par le modèle. Si votre notebook d'entraînement a créé des variables supplémentaires, il faudra les recalculer avant d'appeler **PREDICT**.

## 2. Déposer le fichier dans le Lakehouse

1. Ouvrir [Microsoft Fabric](https://app.fabric.microsoft.com).
2. Ouvrir le **workspace [FORMATION]**.
3. Ouvrir le **Lakehouse** utilisé pour le projet.
4. Aller dans la section **Files**.
5. Cliquer sur **Upload** puis **Files**.
6. Sélectionner le fichier **nouvelles-donnees-predict-batch-100.csv** depuis le dossier **data** du module.
7. Vérifier que le fichier apparaît bien dans le Lakehouse.

## 3. Charger les nouvelles données dans le notebook

1. Ouvrir le notebook utilisé pour l'inférence batch.
2. Lire le fichier CSV depuis le Lakehouse.
3. Vérifier que les colonnes sont correctement interprétées.
4. Afficher un aperçu des données.

Exemple de code :

```python

    spark.read

```

## 4. Préparer les colonnes attendues par le modèle

1. Vérifier que les noms de colonnes correspondent exactement à ceux utilisés à l'entraînement.
2. Convertir les types si nécessaire.
3. Recalculer les variables dérivées si le modèle ne consomme pas directement les colonnes brutes.
4. Enregistrer cette version préparée dans une table ou une vue temporaire.

Exemple de préparation :

```python
from pyspark.sql import functions as F

new_data_prepared = (
    new_data_df
    .withColumn("jour", F.to_date("jour"))
    .withColumn("heure", F.col("heure").cast("int"))
)

new_data_prepared.createOrReplaceTempView("nouvelles_donnees_batch")
```

## 5. Lancer la prévision batch avec PREDICT

1. Ouvrir une cellule SQL dans le notebook, ou utiliser l'interface SQL adaptée à votre environnement Fabric.
2. Appliquer **PREDICT** sur toutes les lignes de la table de nouvelles données.
3. Retourner une colonne contenant la valeur prédite.
4. Vérifier que le nombre de lignes en sortie correspond au nombre de lignes d'entrée.

Exemple de squelette de requête à adapter au nom réel du modèle, de la table et des colonnes :

```sql
SELECT
    station,
    jour,
    heure,
    PREDICT(MODEL => 'prediction_velos_horaires', DATA => *) AS nb_velos_predit
FROM nouvelles_donnees_batch;
```

## 6. Enregistrer les résultats de prévision

1. Enregistrer le résultat dans un dataframe, une table ou un fichier.
2. Donner un nom explicite au résultat, par exemple **predictions_batch_velos**.
3. Réutiliser ensuite ce résultat dans un rapport, une visualisation ou une étape de comparaison.

Exemple de logique dans le notebook :

```python
predictions_df = spark.sql("""
SELECT
    station,
    jour,
    heure,
    PREDICT(MODEL => 'prediction_velos_horaires', DATA => *) AS nb_velos_predit
FROM nouvelles_donnees_batch
""")

display(predictions_df)
```
