# 3.1. Exemples de AI Functions dans Fabric

Ce guide présente plusieurs exemples de **AI Functions** dans Microsoft Fabric, à partir de la documentation officielle **Microsoft Learn**.

Les AI Functions permettent d'appliquer des transformations IA directement sur des données tabulaires dans plusieurs expériences Fabric :

- **Notebooks** avec **pandas** ou **PySpark** ;
- **Warehouse** et **SQL analytics endpoint** avec des fonctions T-SQL ;
- **Dataflow Gen2** pour enrichir des colonnes dans Power Query.

## Prérequis

- Le tenant Fabric autorise **Copilot et les fonctionnalités basées sur Azure OpenAI**.
- Le workspace s'exécute sur une **capacité Fabric payante** compatible.
- La région Fabric utilisée prend en charge les AI Functions.
- Pour les notebooks PySpark Fabric, aucune installation supplémentaire n'est généralement nécessaire.

> Ces points sont repris de la documentation Microsoft Learn sur les AI Functions dans Fabric.

## 1. Comprendre le principe

Dans un notebook, les AI Functions s'utilisent comme des méthodes sur un dataframe, par exemple :

- `df.ai.analyze_sentiment()`
- `df.ai.classify()`
- `df.ai.extract()`
- `df.ai.summarize()`
- `df.ai.translate()`
- `df.ai.generate_response()`

Dans un environnement SQL Fabric, elles existent aussi sous forme de fonctions T-SQL, par exemple :

- `AI_ANALYZE_SENTIMENT()`
- `AI_CLASSIFY()`
- `AI_EXTRACT()`
- `AI_SUMMARIZE()`
- `AI_TRANSLATE()`
- `AI_GENERATE_RESPONSE()`
- `AI_FIX_GRAMMAR()`

## 2. Exemple PySpark : analyser le sentiment

La documentation Microsoft Learn montre que les AI Functions peuvent être utilisées directement sur un dataframe Spark.

Exemple inspiré de Microsoft Learn :

```python
import synapse.ml.spark.aifunc as aifunc

df = spark.createDataFrame([
    ("Le service était excellent et rapide.",),
    ("La piste cyclable était mal entretenue et dangereuse.",),
    ("Le trajet était correct, sans plus.",)
], ["avis"])

sentiment = df.ai.analyze_sentiment(input_col="avis", output_col="sentiment")
display(sentiment)
```

Usage pédagogique :

- analyser des commentaires usagers ;
- qualifier automatiquement des retours libres ;
- enrichir un dataset avant reporting.

## 3. Exemple PySpark : classifier des textes

L'exemple suivant catégorise automatiquement du texte dans une liste d'étiquettes fournies.

```python
df = spark.createDataFrame([
    ("Retard important sur la ligne de bus ce matin.",),
    ("Station vélo propre et bien positionnée.",),
    ("Application mobile difficile à utiliser.",)
], ["commentaire"])

categories = df.ai.classify(
    labels=["transport", "station", "application", "autre"],
    input_col="commentaire",
    output_col="categorie"
)

display(categories)
```

Cet exemple est utile pour :

- catégoriser des réclamations ;
- trier automatiquement des messages ;
- préparer des indicateurs par thème.

## 4. Exemple PySpark : extraire des informations

Microsoft Learn montre aussi comment extraire des entités ou des champs depuis un texte libre.

```python
df = spark.createDataFrame([
    ("Marie Dupont habite à Lyon et travaille comme data analyst.",),
    ("Karim Benali vit à Lille et exerce comme chef de projet.",)
], ["description"])

extraction = df.ai.extract(
    labels=["nom", "ville", "profession"],
    input_col="description"
)

display(extraction)
```

Usage pédagogique :

- structurer des données textuelles ;
- détecter des champs sans regex complexes ;
- préparer un enrichissement avant stockage.

## 5. Exemple PySpark : résumer un texte

La fonction `ai.summarize` permet de produire un résumé court d'un contenu plus long.

```python
df = spark.createDataFrame([
    ("Le service de location de vélos a connu une forte hausse d'utilisation ce week-end, principalement autour des zones touristiques et des grands axes du centre-ville.",)
], ["texte"])

resume = df.ai.summarize(input_col="texte", output_col="resume")
display(resume)
```

Exemple d'usage :

- résumer des verbatims ;
- condenser des comptes rendus ;
- préparer une vue synthétique avant analyse.

## 6. Exemple SQL : AI Functions dans un endpoint SQL ou un Warehouse

Microsoft Learn documente aussi les AI Functions côté SQL dans Fabric.

Exemple `AI_SUMMARIZE` :

```sql
WITH df AS (
    SELECT *
    FROM ( VALUES
        ('Le trafic vélo augmente fortement le matin sur cet axe très fréquenté.')
    ) AS df(texte)
)
SELECT
    texte,
    AI_SUMMARIZE(texte) AS resume
FROM df;
```

Exemple `AI_CLASSIFY` :

```sql
WITH df AS (
    SELECT *
    FROM ( VALUES
        ('La borne est hors service depuis hier.'),
        ('Le parcours est agréable et fluide.'),
        ('Le plan des stations est peu lisible.')
    ) AS df(commentaire)
)
SELECT
    commentaire,
    AI_CLASSIFY(commentaire, 'incident', 'experience', 'signaletique', 'autre') AS categorie
FROM df;
```

Exemple `AI_EXTRACT` :

```sql
SELECT AI_EXTRACT('Le problème a été signalé lundi à Paris', 'jour', 'ville') AS extraction;
```

## 7. Exemple SQL : gérer les erreurs

La documentation Microsoft Learn précise que les AI Functions SQL peuvent retourner `NULL` en cas d'erreur, de contenu bloqué ou de dépassement de limite.

Exemple :

```sql
SELECT
    AI_FIX_GRAMMAR(commentaire NULL ON ERROR) AS texte_corrige
FROM dbo.avis_usagers;
```

Autres options utiles :

- `ERROR ON ERROR` pour faire échouer la requête entière ;
- `DEFAULT <valeur> ON ERROR` pour retourner une valeur de remplacement.

## 8. Exemple multimodal

Microsoft Learn indique que les AI Functions peuvent aussi traiter des **fichiers** comme des PDF, des images, des fichiers texte ou des CSV.

Exemple PySpark de résumé d'un fichier :

```python
custom_df = spark.createDataFrame([
    ("Files/docs/rapport-stations.pdf",)
], ["file_path"])

results = custom_df.ai.summarize(
    input_col="file_path",
    input_col_type="path",
    output_col="summary"
)

display(results)
```

Cet usage est utile pour :

- résumer un document ;
- extraire des informations depuis un fichier ;
- classifier des contenus non structurés.

## 9. Bonnes pratiques à retenir

- Préférer **PySpark** pour les volumes importants, car l'exécution est distribuée.
- Éviter d'appeler plusieurs fois la même transformation IA sur les mêmes données dans une requête SQL.
- Matérialiser les résultats IA dans une table intermédiaire si la sortie doit être réutilisée.
- Vérifier les valeurs `NULL` en sortie côté SQL.
- Relire les résultats produits par l'IA avant diffusion.
