# 0.1. Télécharger le fichier CSV et le déposer dans un Lakehouse Fabric

Ce guide explique comment récupérer le fichier CSV depuis l'API data.gouv.fr puis le déposer dans le **Lakehouse Fabric** du workspace **[FORMATION]**.

## 1. Télécharger le fichier CSV

1. Ouvrir le lien de téléchargement direct du fichier :<br>
   [Fichier CSV data.gouv.fr](https://www.data.gouv.fr/api/1/datasets/r/237382af-0e7a-4ef8-9508-b3e9e78adcfd)
2. Le navigateur ouvre le fichier ou lance son téléchargement automatique selon la configuration.
3. Enregistrer le fichier sur l'ordinateur local dans un dossier facile à retrouver, par exemple le dossier **Téléchargements**.

> **Astuce :** si le navigateur affiche le contenu du CSV dans une page, utiliser l'option de téléchargement du navigateur pour enregistrer le fichier en local.

> **Zone capture d'écran 1** : insérer ici une capture du navigateur montrant le téléchargement ou l'aperçu du fichier CSV.

## 2. Ouvrir le workspace Fabric

1. Se connecter à [Microsoft Fabric](https://app.fabric.microsoft.com).
2. Ouvrir le **workspace [FORMATION]**.
3. Ouvrir le **Lakehouse** cible. Si aucun Lakehouse n'existe encore, en créer un avant de poursuivre.

> **Zone capture d'écran 2** : insérer ici une capture du workspace [FORMATION] avec le Lakehouse cible visible.

## 3. Déposer le CSV dans le Lakehouse

1. Dans le Lakehouse, ouvrir la section **Files**.
2. Cliquer sur **Upload** puis choisir **Files**.
3. Sélectionner le fichier CSV téléchargé à l'étape précédente.
4. Patienter pendant l'import du fichier.
5. Vérifier que le fichier apparaît bien dans le dossier **Files** du Lakehouse.

> **Zone capture d'écran 3** : insérer ici une capture de la zone Files du Lakehouse pendant ou après l'import du CSV.

## 4. Vérifier le dépôt

1. Cliquer sur le fichier pour confirmer qu'il est bien présent.
2. Si besoin, renommer le fichier pour faciliter son utilisation dans les exercices du module.
3. Noter le nom exact du fichier pour la suite du parcours Data Science.

Le fichier CSV est maintenant disponible dans le Lakehouse Fabric du workspace **[FORMATION]** et peut être utilisé pour les étapes suivantes.
