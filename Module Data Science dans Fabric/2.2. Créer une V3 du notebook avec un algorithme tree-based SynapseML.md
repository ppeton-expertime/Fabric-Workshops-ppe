
## 5. Entraîner un modèle tree-based avec SynapseML

1. Choisir un algorithme tree-based de SynapseML, par exemple **LightGBMRegressor**.
2. Définir quelques hyperparamètres de départ.
3. Construire un pipeline complet.
4. Entraîner le modèle sur les données d'apprentissage.

Exemple de code :

```python
regressor = LightGBMRegressor(
    labelCol="nb_velos",
    featuresCol="features",
    objective="regression",
    numIterations=100,
    learningRate=0.1,
    numLeaves=31
)

pipeline = Pipeline(stages=[station_indexer, assembler, regressor])
```
