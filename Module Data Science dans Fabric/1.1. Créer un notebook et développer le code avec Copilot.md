# 1.1. Créer un notebook et développer le code avec Copilot

Ce guide explique comment créer un notebook dans Microsoft Fabric, charger les données du Lakehouse dans un dataset exploitable, puis utiliser Copilot pour écrire le code nécessaire aux tâches suivantes :

- pour une station, créer la série temporelle jour-heure du nombre de vélos comptabilisés ;
- établir un modèle prédictif du nombre de vélos par heure.

## Prérequis

- Le fichier CSV a été téléchargé puis déposé dans le **Lakehouse Fabric** du workspace **[FORMATION]**.
- Un **Lakehouse** est disponible dans le workspace.
- L'accès à **Copilot dans Fabric** est activé.

4. Donner un nom explicite au notebook, par exemple **Notebook - Prévision vélos**.
5. Associer le notebook au **Lakehouse** contenant le fichier CSV.

## 4. Construire la série temporelle jour-heure

1. Identifier la colonne de date et heure dans le dataset.
2. Convertir cette colonne au bon format si nécessaire.
3. Extraire le jour et l'heure.
4. Compter le nombre de vélos pour chaque combinaison station + jour + heure.

Exemple de prompt à donner à Copilot :

```text
À partir du dataset chargé, crée une série temporelle jour-heure du nombre de vélos comptabilisés pour une station donnée.
Groupe les données par station, jour et heure, puis calcule le nombre d'enregistrements.
Affiche le résultat sous forme de tableau puis trace une courbe simple.
```

Exemple de structure logique du code :

```python
df_time = (
    df
    .withColumn("date_time", F.to_timestamp(F.col("date_time_col")))
    .withColumn("jour", F.to_date("date_time"))
    .withColumn("heure", F.hour("date_time"))
)

serie_temporelle = (
    df_time
    .groupBy("station", "jour", "heure")
    .agg(F.count("*").alias("nb_velos"))
    .orderBy("station", "jour", "heure")
)

display(serie_temporelle)
```
