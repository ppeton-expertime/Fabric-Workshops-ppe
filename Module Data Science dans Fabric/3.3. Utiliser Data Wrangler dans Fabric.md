## 3. Nettoyer les colonnes

Sur le fichier de comptage vélo, plusieurs transformations sont intéressantes dès l'ouverture dans Data Wrangler :

- renommer les colonnes longues ou ambiguës ;
- supprimer les espaces inutiles dans les noms ;
- uniformiser les minuscules et les séparateurs ;
- garder des noms de colonnes plus simples à utiliser ensuite dans le code.

Exemple de transformation utile :

- `Date et heure de comptage` -> `date_heure_comptage`
- `Nom du site de comptage` -> `nom_site`
- `Comptage horaire` -> `nb_velos`

Dans Data Wrangler, cette étape permet de voir immédiatement l'impact du renommage sur la lisibilité du dataframe.

## 4. Corriger les types de données

Le fichier contient des colonnes qui ne sont pas toutes prêtes à être utilisées telles quelles.

Exemples de conversions intéressantes :

- convertir la date et l'heure de comptage en type timestamp ;
- convertir le comptage horaire en valeur numérique ;
- extraire la date, l'heure et le jour de semaine ;
- garder les colonnes texte pour les dimensions métier comme la station ou le site.

Exemple de code généré ou inspiré par Data Wrangler :

```python
from pyspark.sql import functions as F

df_time = (
    normalized_df
    .withColumn("date_time", F.to_timestamp("date_et_heure_de_comptage"))
    .withColumn("jour", F.to_date("date_time"))
    .withColumn("heure", F.hour("date_time"))
    .withColumn("nb_velos", F.col("comptage_horaire").cast("double"))
)
```

Cette transformation est l'une des plus utiles avant un futur entraînement de modèle ou une analyse temporelle.

## 5. Gérer les valeurs manquantes

Data Wrangler permet aussi d'identifier rapidement les colonnes qui contiennent des valeurs vides ou nulles.

Sur ce jeu de données, plusieurs stratégies peuvent être utiles :

- supprimer les lignes sans valeur cible `nb_velos` ;
- remplacer certaines valeurs manquantes par une valeur par défaut ;
- filtrer les lignes inexploitables ;
- conserver les colonnes métier utiles et écarter les colonnes trop bruitées.

Exemple de logique de nettoyage :

```python
serie_temporelle = (
    df_time
    .select("station", "jour", "heure", "nb_velos")
    .where(F.col("nb_velos").isNotNull())
)
```

## 6. Filtrer et trier les données

Une fois les colonnes préparées, Data Wrangler est pratique pour explorer des sous-ensembles simples :

- filtrer une station précise ;
- trier par date ou par volume de trafic ;
- observer les heures les plus chargées ;
- repérer les lignes extrêmes ou incohérentes.

Exemple d'usage pédagogique :

2. Trier par `nb_velos` décroissant.

Ce type d'exploration aide à mieux comprendre les données avant de construire un modèle.

## 7. Créer de nouvelles variables

Data Wrangler permet également de générer des colonnes dérivées qui enrichissent le dataset.

Quelques transformations intéressantes sur ce cas d'usage :

- extraire le jour de semaine ;
- extraire le mois ;
- extraire l'année ;
- créer une colonne de période de la journée ;
- regrouper les heures en créneaux simples.

Exemple de code équivalent :

```python
prepared_df = (
    serie_temporelle
    .withColumn("jour_semaine", F.dayofweek("jour"))
    .withColumn("mois", F.month("jour"))
    .withColumn("annee", F.year("jour"))
)
```

Ces variables sont ensuite très utiles pour :

- l'entraînement d'un premier modèle ;
- la comparaison avec FLAML ou AutoML ;
- l'analyse de la saisonnalité des comptages.

## 8. Agréger les données pour l'analyse

Une autre force de Data Wrangler est de permettre des agrégations rapides avant de passer au code.

Exemples de transformations pertinentes :

- compter le nombre de lignes par station ;
- calculer une moyenne de vélos par heure ;
- regrouper les données par jour de semaine ;
- comparer les stations les plus fréquentées.

Exemple de logique possible :

```python
resume_station = (
    prepared_df
    .groupBy("station")
    .agg(
        F.avg("nb_velos").alias("moyenne_velos"),
        F.count("*").alias("nb_lignes")
    )
    .orderBy(F.desc("moyenne_velos"))
)
```

Cette étape est intéressante pour transformer une vue brute en vue de synthèse plus lisible.
