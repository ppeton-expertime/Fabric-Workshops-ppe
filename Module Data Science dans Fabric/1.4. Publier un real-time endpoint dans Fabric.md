# 1.4. Publier un real-time endpoint dans Fabric

Ce guide explique comment publier un **real-time endpoint** dans Microsoft Fabric à partir d'un modèle prêt à être exposé pour des consommations en temps réel.

## Prérequis

- Le modèle ou l'artefact source est déjà préparé.
- Le workspace **[FORMATION]** est disponible.
- L'accès aux fonctionnalités **Real-Time Intelligence** ou à la publication du endpoint est autorisé.

## 1. Ouvrir l'artefact à publier

1. Se connecter à [Microsoft Fabric](https://app.fabric.microsoft.com).
2. Ouvrir le **workspace [FORMATION]**.
3. Repérer l'élément source à publier, par exemple un modèle, un flux ou un artefact prêt pour la diffusion temps réel.
4. Ouvrir le menu d'actions de l'élément.

> **Zone capture d'écran 1** : insérer ici une capture de l'élément source et du menu d'actions permettant d'accéder à la publication.

## 2. Démarrer la publication du real-time endpoint

1. Cliquer sur l'option de publication ou de création du **real-time endpoint**.
2. Vérifier le nom proposé pour le endpoint.
3. Compléter si besoin la description, les paramètres ou les options de publication.
4. Valider l'opération.

Exemple de points à contrôler avant validation :

- le nom du endpoint est explicite ;
- le workspace cible est le bon ;
- les paramètres de publication correspondent au besoin métier.

> **Zone capture d'écran 2** : insérer ici une capture de l'écran de publication montrant le nom du endpoint et les paramètres avant validation.

## 3. Vérifier la création du endpoint

1. Attendre la fin du déploiement ou de la génération du endpoint.
2. Revenir à la liste des éléments du workspace.
3. Vérifier que le **real-time endpoint** apparaît bien dans la liste.
4. Ouvrir le endpoint pour confirmer qu'il est disponible.

> **Zone capture d'écran 3** : insérer ici une capture du workspace montrant le real-time endpoint publié.

## 4. Contrôler le bon fonctionnement

1. Ouvrir le endpoint publié.
2. Vérifier les informations exposées, l'URL ou l'identifiant d'accès, selon l'interface disponible.
3. Tester une première requête si l'option est proposée.
4. S'assurer que le endpoint répond correctement.

## 5. Finaliser la mise à disposition

1. Noter le nom exact du endpoint pour les étapes suivantes.
2. Conserver le lien ou l'identifiant de publication.
3. Documenter dans le support de formation le moment de publication et l'usage attendu.

Le real-time endpoint est maintenant publié dans Fabric et prêt à être utilisé par les scénarios temps réel du module Data Science.
