# 2.1. Créer une V2 du notebook avec tuning FLAML

Ce guide explique comment créer une seconde version du notebook d'entraînement afin d'améliorer le modèle en ajoutant un **tuning des hyperparamètres** avec la librairie **FLAML**.

## Prérequis

- Un premier notebook d'entraînement existe déjà.
- Le dataset de comptage de vélos est disponible dans le Lakehouse du workspace **[FORMATION]**.
- Un premier modèle a déjà été entraîné et évalué.
- L'accès à Copilot dans Fabric est activé.

## 1. Dupliquer le notebook d'entraînement

1. Ouvrir le notebook utilisé pour la première version du modèle.
2. Créer une copie du notebook.
3. Renommer cette copie, par exemple **Notebook - Prévision vélos - V2**.
4. Conserver la même connexion au Lakehouse.

## 2. Préparer la V2 pour le tuning

1. Reprendre les étapes de chargement des données et de préparation du dataset.
2. Vérifier que la variable cible est toujours le **nombre de vélos par heure**.
3. Contrôler que les variables explicatives sont bien prêtes pour l'entraînement.
4. Ajouter une nouvelle section dédiée au tuning des hyperparamètres.

Exemple de prompt à donner à Copilot :

```text
Ajoute une seconde version du notebook d'entraînement.
Conserve le chargement des données et la préparation du dataset, puis ajoute une étape de tuning des hyperparamètres avec la librairie FLAML pour prédire le nombre de vélos par heure.
```

## 4. Préparer les données pour FLAML

1. Convertir le dataset dans un format exploitable par FLAML, généralement en Pandas.
2. Sélectionner les colonnes d'entrée utiles.
3. Isoler la colonne cible.
4. Séparer les données en apprentissage et en test.

Exemple de prompt à donner à Copilot :

```text
Prépare les données pour un entraînement avec FLAML.
Convertis le dataset si nécessaire, définis les variables explicatives, la cible, puis crée un découpage train/test.
```

Exemple de structure logique :

```python
pdf = prepared_df.toPandas()

X = pdf[["station", "jour", "heure"]]
y = pdf["nb_velos"]
```

## 5. Lancer le tuning des hyperparamètres

1. Créer une instance `AutoML`.
2. Définir la tâche en mode **regression**.
3. Fixer une contrainte de temps raisonnable pour la recherche.
4. Lancer l'entraînement et laisser FLAML tester plusieurs configurations.

Exemple de prompt à donner à Copilot :

```text
Écris le code Python pour lancer un tuning d'hyperparamètres avec FLAML sur une tâche de régression.
Le modèle doit prédire le nombre de vélos par heure et retourner les meilleurs paramètres trouvés.
```

Exemple de code :

```python
automl = AutoML()

automl.fit(
    X_train=X_train,
    y_train=y_train,
    task="regression",
    time_budget=60,
    metric="rmse"
)

print(automl.best_estimator)
print(automl.best_config)
print(automl.best_loss)
```
