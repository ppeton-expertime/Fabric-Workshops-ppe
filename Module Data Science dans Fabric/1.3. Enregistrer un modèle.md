# 1.3. Enregistrer un modèle

Ce guide explique comment enregistrer un modèle entraîné dans Microsoft Fabric afin de le réutiliser, le comparer ou le déployer plus tard.

## Prérequis

- Un notebook a déjà été créé.
- Un modèle a été entraîné avec succès.
- Les résultats ont été validés avec MLflow ou dans le notebook.

## 1. Identifier le modèle à conserver

1. Vérifier que le run associé au meilleur modèle a bien été sélectionné.
2. Contrôler les métriques principales avant l'enregistrement.
3. S'assurer que le modèle correspond bien à l'objectif métier.

> **Zone capture d'écran 1** : insérer ici une capture du notebook montrant le run retenu, les métriques et le modèle sélectionné.

## 2. Enregistrer le modèle avec MLflow

1. Dans le notebook, utiliser MLflow pour journaliser le modèle.
2. Donner un nom clair au modèle.
3. Ajouter si besoin une description ou des tags pour faciliter la recherche.

Exemple de code :

```python
import mlflow

with mlflow.start_run():
    mlflow.log_param("modele", "prediction_velos_horaires")
    mlflow.log_metric("rmse", 12.5)
    mlflow.sklearn.log_model(model, artifact_path="model")
```

## 3. Vérifier l'enregistrement

1. Ouvrir le volet **MLflow** ou l'expérience associée.
2. Vérifier que le run contient bien le modèle enregistré.
3. Contrôler la présence des artefacts générés.
4. S'assurer que le nom du modèle est lisible et cohérent.

> **Zone capture d'écran 3** : insérer ici une capture de l'expérience MLflow montrant le modèle dans les artefacts du run.

## 4. Conserver une version exploitable

1. Noter le nom du run et la date d'enregistrement.
2. Garder la référence du modèle pour les étapes suivantes.
3. Si plusieurs versions existent, identifier clairement la meilleure version.

## 5. Préparer la suite du parcours

1. Utiliser le modèle enregistré pour les tests de prédiction.
2. Réutiliser le run ou le modèle pour comparer d'autres essais.
3. Documenter le résultat dans le notebook ou dans le support de formation.

Le modèle est maintenant enregistré et prêt à être réutilisé dans les étapes suivantes du module Data Science.
